## Quick capture rules (your existing job-photo standards apply)

- Shoot the ground lap first, then roof details — but for the website, **whole-front-elevation shots are the priority**.
- Same time of day / similar light across the set makes the gallery feel like a portfolio.
- Landscape orientation, fill the frame with the house, no trucks/signs/crew faces unless you want them there.
- Homeowner permission before using any identifiable address/customer photo.
- Export ~2000px wide JPEG, quality ~80 (under ~500 KB each).

## Growing the gallery later

Each new project card = one `<article>` block in `projects/index.html` (copy an existing one) + one image in
`assets/img/`. Real jobs should also be captioned with suburb + shingle line, e.g. "Landmark PRO · Moire Black ·
Powell" — that's what ranks and sells.
